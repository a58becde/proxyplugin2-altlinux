# Приёмка на машине

Порядок важен: варианты проверяются по очереди на одной машине, чтобы следы
одного не маскировали другой.

## 0. Подписанный xpi на месте и это действительно он

```bash
unzip -l sedd/proxyplugin2-firefox.xpi | grep META-INF
```

Должны быть `META-INF/mozilla.rsa`, `mozilla.sf`, `manifest.mf` — это подпись.
Если их нет, положена неподписанная сборка, и Firefox её проигнорирует.

```bash
unzip -p sedd/proxyplugin2-firefox.xpi manifest.json | grep -A3 gecko
```

`id` обязан совпадать с `FW_XPI_ID` в `lib/firewyrm.sh` и `fw_xpi_id`
в `ansible/firewyrm_vars.yml`. Установщик это проверяет сам и откажется
работать при расхождении, но лучше знать заранее.

## 1. Установка через sh

```bash
su -
/путь/к/install.sh
```

В выводе должны быть строки `id совпадает` и `подпись на месте`. Затем:

```bash
/путь/к/install.sh --check
```

Ни одного `[ !! ]`.

## 2. Функциональная проверка

**Chromium.** Полностью закрыть, открыть заново. `chrome://policy` — политика
видна. `chrome://extensions` — расширение установлено политикой. Открыть СЭДД
и выполнить реальную операцию с ЭП.

**Firefox.** Полностью закрыть, открыть заново. `about:addons` — расширение
включено. Проверка плагинов в СЭДД проходит **с первого раза**: если требуется
второй перезапуск браузера, значит не применилась политика
`/etc/firefox/policies/policies.json` — проверьте, не защищён ли файл от записи
(`lsattr`), установщик в этом случае пишет предупреждение.

## 3. Удаление через sh

```bash
/путь/к/uninstall.sh
```

```bash
/путь/к/install.sh --check
```

Здесь проверка обязана **упасть** — это и есть доказательство удаления.
Расширение исчезнет из браузеров после их перезапуска: до этого Chromium и
Firefox помнят его в своих базах.

## 4–6. То же через Ansible

```bash
cd /etc/ansible/playbook
ansible-playbook -i /etc/ansible/hosts firewyrm_install.yml -e fw_hosts=ws-01
```

Проверка — тем же `install.sh --check` на машине: он не зависит от способа
установки. Затем функциональная проверка по пункту 2 и удаление:

```bash
ansible-playbook -i /etc/ansible/hosts firewyrm_uninstall.yml -e fw_hosts=ws-01
```

Плейбук завершается ассертой и упадёт сам, если что-то осталось.

## 7. Выкатка

```bash
ansible-playbook -i /etc/ansible/hosts firewyrm_install.yml -e fw_hosts=ws-01,ws-02,ws-03
```

Перед выкаткой убедитесь, что на управляющем узле лежат актуальные плейбуки и
каталог `sedd/` с подписанным xpi: Ansible раздаёт файлы с него, а не с
рабочей станции.
